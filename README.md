Sistema de Registro de Visitantes
Aplicación de escritorio desarrollada en **Python con Tkinter** que permite gestionar el ingreso de visitantes a una oficina mediante operaciones CRUD (Crear, Leer, Actualizar y Eliminar).

Características
- Registro de nuevos visitantes
- Visualización en tabla dinámica (Treeview)
- Actualización de datos
- Eliminación de registros con confirmación
- Limpieza automática de campos
- Validación de datos (campos obligatorios y cédula única)
